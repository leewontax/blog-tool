# 블로그 글 작성 도우미 (세무사용)

네이버 블로그에 올릴 세무 글을 **AI로 초안 작성 → 다듬기 → 복사해서 붙여넣기**까지 도와주는 웹 프로그램입니다.
내 컴퓨터에서 실행하고, 브라우저(크롬·엣지)로 사용합니다.

> **왜 "자동 업로드"가 아니라 "복사"인가요?**
> 네이버는 외부 프로그램이 블로그에 글을 올리는 공식 통로(글쓰기 API)를 2020년 5월 6일에 종료했습니다.
> 프로그램이 로그인해서 대신 올리는 방식은 약관 위반·계정 제한 위험이 있어, 안전한 복사·붙여넣기 방식으로 만들었습니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| AI 글 초안 | 주제·독자·메모를 넣으면 초안을 작성합니다. 확실하지 않은 조문·금액·기한은 지어내지 않고 **[확인 필요]**로 표시합니다. |
| 공식 자료 검색 | 체크하면 국가법령정보센터·국세청·기획재정부 등 **공식 사이트만** 검색해서 쓰고, 참고한 링크를 보여 줍니다. |
| 세무 글 템플릿 | 세무 칼럼 / 신고기한 안내 / 세법 개정 소식 / Q&A 기본 제공, 직접 추가·수정 가능 |
| 추천 주제 TOP 5 | 지역(기본 안성시) 소식·세금 신고 일정·세법 개정을 AI가 검색해 지금 쓰면 좋을 주제 5개를 추천합니다. 위쪽 띠에 실시간 검색어처럼 돌아가며 표시되고, 12시간마다 자동으로 새로 조사합니다. |
| 내 글 학습(말투 반영) | 내가 쓴 블로그 글을 넣어 두면 AI가 그 말투·구성을 따라 씁니다. 말투 요약을 AI가 분석하고 직접 고칠 수도 있습니다. |
| 제목·태그 추천 | 네이버 검색에 맞춘 제목 후보 5개, 해시태그 10개 |
| 서식 유지 복사 | 소제목·굵게·목록·표 서식이 그대로 네이버 에디터에 붙도록 복사 |
| 글 보관·발행 일정 | 초안 / 발행 예정 / 발행 완료 관리, 예정일이 지난 글 표시, 백업·복원 |

## 처음 한 번 설정

1. **Node.js 설치** — https://nodejs.org 에서 LTS(22 이상) 버전을 받아 설치합니다.
2. 이 폴더에서 명령 프롬프트(터미널)를 열고 실행합니다.
   ```
   npm install
   ```
3. **AI 키 넣기**
   - https://console.anthropic.com 에서 API 키를 발급받습니다. (사용한 만큼 요금이 나오는 유료 서비스입니다)
   - `.env.example` 파일을 복사해 이름을 `.env`로 바꾸고, `ANTHROPIC_API_KEY=` 뒤에 키를 붙여 넣고 저장합니다.
   - ⚠ API 키는 비밀번호와 같습니다. 다른 사람에게 보내거나 블로그·메신저에 올리지 마세요.
   - 키가 없어도 프로그램은 켜지며, 글 보관·복사 기능은 쓸 수 있습니다.

## 매번 사용할 때

```
npm start
```
브라우저에서 **http://localhost:3000** 을 엽니다. (끝낼 때는 터미널에서 `Ctrl + C`)

### 내 말투로 쓰게 하기 (처음 한 번, 이후 가끔)
1. **내 글 학습** 화면에서 내 블로그 글 3~5개를 붙여넣고 **글 저장**
   - 고객 실명·연락처 등 개인정보는 지우고 넣어 주세요.
2. **말투 분석하기** → 결과를 읽어 보고 필요하면 고친 뒤 **요약 저장**
3. **글쓰기** 화면에서 **내 말투 반영**이 체크되어 있으면 그 말투로 초안이 작성됩니다.

> 이것은 AI를 다시 훈련시키는 것이 아니라, 글을 쓸 때마다 내 글을 예시로 함께 보여 주는 방식입니다.
> 예시 글의 세법 내용·세율·금액은 따라 하지 않도록 지시되어 있습니다.
> 예시 글이 많을수록 글 1편당 AI 요금이 조금 늘어납니다(예시 글은 최대 약 15,000자까지 사용).

### 추천 주제 TOP 5
- **글쓰기** 화면 왼쪽 위에 표시됩니다. **이 주제로 쓰기**를 누르면 주제와 메모가 채워집니다.
- 📍 지역 이름을 누르면 지역을 바꿀 수 있습니다.
- 순위 옆 ▲▼는 직전 조사 대비 순위 변화, NEW는 새로 들어온 주제입니다.
- 막대는 **AI가 추정한 관심도**이며 실제 검색량이 아닙니다.
- (선택) 네이버 데이터랩 키를 `.env`에 넣으면 막대 대신 **실제 최근 4주 검색 추이 그래프**가 표시됩니다.
  - 네이버 개발자센터(developers.naver.com)에서 애플리케이션을 등록하고 '데이터랩(검색어트렌드)' API를 선택해 발급합니다.
  - `.env`에 `NAVER_CLIENT_ID=`, `NAVER_CLIENT_SECRET=` 두 줄로 넣습니다.
  - 데이터랩 수치는 **전국 기준 상대값**(5개 주제끼리 비교한 값)입니다. 안성 지역만의 검색량은 아닙니다.
- 프로그램을 켜 두면 12시간마다 자동으로 새로 조사합니다. 조사 1회마다 AI 요금(웹검색 포함)이 나옵니다. 간격은 `.env`의 `TOPIC_REFRESH_HOURS`로 바꿀 수 있습니다.

### 글 올리는 순서
1. **글쓰기** 화면에서 주제를 넣고 **AI 초안 작성**
2. 본문을 읽고 고칩니다. 특히 노란색 **[확인 필요]** 부분은 법령·국세청 자료로 직접 확인 후 고칩니다.
3. **제목·태그 추천받기** → 마음에 드는 제목 클릭
4. **저장** (Ctrl+S)
5. **네이버 글쓰기 창 열기** → 제목 복사·붙여넣기 → 본문 복사·붙여넣기 → 태그 복사·붙여넣기
6. 네이버에서 발행한 뒤, 글 주소를 **네이버 글 주소** 칸에 넣고 상태를 **발행 완료**로 저장

## 꼭 지켜 주세요

- **AI 초안을 그대로 발행하지 마세요.** 세율·공제한도·기한·조문 번호는 반드시 직접 확인해야 합니다. 본문에 [확인 필요]가 남아 있으면 복사할 때 경고가 나옵니다.
- 고객 실명·주민등록번호·계좌번호 등 **개인정보를 메모에 넣지 마세요.** 메모 내용은 AI 서버로 전송됩니다.
- 세무사 광고 관련 규정에 어긋나는 표현(과장·비교·단정 표현 등)이 없는지 발행 전에 확인해 주세요. AI에는 이런 표현을 피하도록 지시해 두었습니다.

## 데이터 보관

- 글과 템플릿은 이 폴더의 `data` 폴더에만 저장됩니다. (인터넷에 올라가지 않음)
- 삭제한 글은 `data/trash.json`에 남아 있어 되살릴 수 있습니다.
- **글 목록 → 백업 파일 내려받기**로 정기적으로 백업해 두세요. 복원할 때는 복원 직전 상태가 `data` 폴더에 자동으로 따로 저장됩니다.
- 이 프로그램은 내 컴퓨터(127.0.0.1)에서만 접속되도록 되어 있습니다.

## 파일 구성

```
server.js        서버 (AI 요청, 글·템플릿 저장)
public/          화면 (index.html, style.css, app.js)
data/            저장된 글 (자동 생성, 깃에 올라가지 않음)
.env             API 키 (직접 생성, 깃에 올라가지 않음)
```
