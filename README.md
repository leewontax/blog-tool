# 블로그 글 작성 도우미 (세무사용)

네이버 블로그에 올릴 세무 글을 **AI로 초안 작성 → 다듬기 → 복사해서 붙여넣기**까지 도와주는 웹 프로그램입니다.
내 컴퓨터에서 실행하고, 브라우저(크롬·엣지)로 사용합니다.

> **왜 "자동 업로드"가 아니라 "복사"인가요?**
> 네이버는 외부 프로그램이 블로그에 글을 올리는 공식 통로(글쓰기 API)를 2020년 5월 6일에 종료했습니다.
> 프로그램이 로그인해서 대신 올리는 방식은 약관 위반·계정 제한 위험이 있어, 안전한 복사·붙여넣기 방식으로 만들었습니다.

> **추가 비용 없이 사용합니다 (요청문 복사 방식)**
> 이 앱은 AI에 직접 연결하지 않습니다. 앱이 **요청문**을 만들어 복사해 주면, 세무사님이 **claude.ai 대화창**(구독 요금에 포함)에 붙여넣고, 답변을 다시 앱에 붙여넣는 방식입니다.
> API 키를 넣지 않는 한 **추가 요금은 0원**입니다.

## 주요 기능

| 기능 | 설명 |
|---|---|
| AI 글 초안 | 주제·독자·메모를 넣으면 claude.ai에 붙여넣을 요청문을 만들어 줍니다. 답변을 붙여넣으면 제목 후보·본문·해시태그가 자동으로 채워집니다. 본문에는 **법령명·조문 번호를 쓰지 않고** 쉬운 말로만 설명하며, 확실하지 않은 금액·기한은 지어내지 않고 본문에서 숫자를 뺀 뒤, 본문 밖 **'발행 전 확인할 내용'** 체크리스트로 따로 정리합니다(네이버에 복사되지 않음). |
| 공식 자료 확인 | 체크하면 국가법령정보센터·국세청·기획재정부 등 **공식 자료로 확인**하라는 요청과 출처 링크 요청이 들어갑니다. (claude.ai에서 웹 검색이 켜져 있어야 합니다) |
| 세무 글 템플릿 | 세무 칼럼 / 신고기한 안내 / 세법 개정 소식 / Q&A 기본 제공, 직접 추가·수정 가능 |
| 추천 주제 TOP 5 | **🔄 갱신** 버튼을 누르면 세무달력 기한·시기별 주제·지역(기본 안성시) 뉴스로 지금 쓰면 좋을 주제 5개를 바로 추천합니다(무료). 위쪽 띠에 실시간 검색어처럼 돌아가며 표시됩니다. 더 깊은 조사는 AI 정밀 조사(요청문 복사)로 할 수 있습니다. |
| 이미지 학습 | 내 블로그의 **본문 이미지**와 **대표 이미지**를 따로 넣어 두면, 앱이 주요 색을 자동으로 뽑고 AI가 디자인 양식(스타일 지침)을 정리해 둡니다. 새 이미지 요청문에 자동으로 반영되어 비슷한 양식으로 만들어집니다. |
| 내 글 학습(말투 반영) | 내가 쓴 블로그 글을 넣어 두면 AI가 그 말투·구성을 따라 씁니다. 말투 요약을 AI가 분석하고 직접 고칠 수도 있습니다. |
| 세무달력 | 블로그로 공지할 만한 **주요 세목**(부가세·종소세·법인세·종부세·사업장현황신고·근로자녀장려금·연말정산)의 기한을 달력에 표시합니다. 휴일이면 연장된 기한으로 계산하고, **언제 안내 글을 올리면 좋은지** 추천일을 함께 보여 줍니다. |
| 이미지 만들기 | **본문 이미지**: claude.ai가 요약 카드·일정표·비교표·체크리스트 같은 도표형 이미지를 만들고, 본문의 알맞은 소제목 아래에 자리를 표시합니다. **대표 이미지**: ChatGPT가 제목 글자까지 넣어 그리고, 앱에서 넣을 제목과 비교·확인합니다. |
| 2차 검증 (ChatGPT) | 완성한 글을 ChatGPT가 다시 확인합니다. 세율·한도·기한, '발행 전 확인할 내용', 본문에 법령명·조문이 들어갔는지, 계산, 광고 표현, 개인정보를 점검해 **발행 가능 / 수정 후 발행 / 발행 보류**로 판정합니다. 결과는 글과 함께 저장되고, 검증 결과를 반영한 **수정본**을 만들 수 있습니다(되돌리기 가능). |
| 제목·태그 추천 | 네이버 검색에 맞춘 제목 후보 5개, 해시태그 10개 |
| 서식 유지 복사 | 소제목·굵게·목록·표 서식이 그대로 네이버 에디터에 붙도록 복사 |
| 글 보관·발행 일정 | 초안 / 발행 예정 / 발행 완료 관리, 예정일이 지난 글 표시, 백업·복원 |

## 처음 한 번 설정 (윈도우)

1. **Node.js 설치** — https://nodejs.org 에서 LTS(22 이상) 버전을 받아 설치합니다.
2. 프로그램 폴더의 **`make-desktop-icon.bat`** 을 더블클릭합니다.
   - 바탕화면에 **'블로그 글 도우미'** 아이콘이 생깁니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 **추가 정보 → 실행**을 누릅니다(인터넷에서 받은 파일이라 한 번 묻는 것입니다).
   - 프로그램 폴더를 다른 곳으로 옮겼다면 이 파일을 다시 실행해 주세요.
   - **아이콘이 안 생기면**
     - ZIP 파일 안에서 바로 실행하지 말고, 먼저 **모두 압축 풀기**를 한 뒤 풀린 폴더에서 실행하세요.
     - 바탕화면을 클릭하고 **F5**(새로 고침)를 눌러 보세요.
     - 보안 프로그램(V3·알약 등)이 막으면 자동으로 다른 방법으로 다시 시도합니다. 그래도 안 되면 **직접 만들기**: `start-blog-tool.bat` 오른쪽 클릭 → (윈도우 11은 '추가 옵션 표시') → **보내기 → 바탕 화면에 바로 가기 만들기**
3. **API 키는 넣지 않습니다.** `.env` 파일도 만들지 않아도 됩니다.
   - 화면 오른쪽 위에 **"요청문 복사 방식 · 추가 비용 없음"**이 보이면 정상입니다.
   - (참고) `.env`에 `ANTHROPIC_API_KEY`를 넣으면 버튼 한 번으로 바로 작성되는 대신 **사용한 만큼 API 요금이 나옵니다.** 추가 비용을 원하지 않으면 넣지 마세요.

## 매번 사용할 때

- 바탕화면의 **'블로그 글 도우미' 아이콘을 더블클릭**하면 프로그램이 켜지고 브라우저가 자동으로 열립니다.
  - 요청문 복사 방식(무료)은 **따로 설치할 부품이 없어** 바로 켜집니다. (API 키를 넣은 경우에만 AI 연결 부품을 자동 설치)
  - 이미 켜져 있으면 브라우저만 다시 엽니다.
- 작업 표시줄에 **'블로그 글 도우미'** 창이 최소화되어 있습니다. **이 창을 닫으면 프로그램이 꺼집니다.**
- (명령어로 실행하려면) 폴더에서 `npm start` → 브라우저에서 http://localhost:3000 (`npm install`은 API 키를 쓸 때만 필요)

### 자동 저장·이전 버전
- 글을 고치면 **20초 뒤 자동 저장**됩니다. 다른 창으로 가거나 브라우저를 닫을 때도 저장합니다. 저장 상태는 오른쪽 위에 "자동 저장됨 · 시각"으로 표시됩니다.
- **이전 버전**: 저장할 때 직전 내용을 보관합니다(10분에 한 번, 또는 크게 고칠 때·수정본 적용·되돌리기 전 · 글마다 최근 30개). 오른쪽 위 **이전 버전** 버튼 → 미리보기 → 되돌리기.

### 자동 백업
- 프로그램이 켜져 있으면 **하루 한 번** 저장한 글·설정 전체(`data` 폴더)를 날짜별 폴더로 자동 백업합니다. **최근 30일치**만 보관합니다.
- 기본 위치는 프로그램 폴더 안 `backups` 폴더입니다. 컴퓨터 고장에 대비해 **글 목록 → 자동 백업 → 백업 위치**를 OneDrive 같은 클라우드 폴더로 지정하세요(**OneDrive 폴더 사용** 버튼).
- 백업에서 되살릴 때: 프로그램을 끈 뒤, 백업 폴더의 날짜 폴더 안 파일들을 프로그램 폴더의 `data` 폴더에 덮어쓰고 다시 켭니다. (덮어쓰기 전에 지금 `data` 폴더를 따로 복사해 두세요.)

### 내 말투로 쓰게 하기 (처음 한 번, 이후 가끔)
1. **내 글 학습** 화면에서 내 블로그 글 3~5개를 붙여넣고 **글 저장**
   - 고객 실명·연락처 등 개인정보는 지우고 넣어 주세요.
2. **말투 분석 요청문 복사** → claude.ai에 붙여넣어 보내기 → 답변을 복사해 **말투 요약** 칸에 붙여넣고, 필요하면 고친 뒤 **요약 저장**
3. **글쓰기** 화면에서 **내 말투 반영**이 체크되어 있으면 그 말투로 초안이 작성됩니다.

> 이것은 AI를 다시 훈련시키는 것이 아니라, 글을 쓸 때마다 내 글을 예시로 함께 보여 주는 방식입니다.
> 예시 글의 세법 내용·세율·금액은 따라 하지 않도록 지시되어 있습니다.
> 예시 글은 요청문에 최대 약 15,000자까지 들어갑니다.

### 이미지 만들기 (글쓰기 화면 '4. 이미지 만들기' — 2차 검증 다음 단계)
**본문 이미지 (claude.ai · 도표형)**
1. 개수(2~4개)를 고르고 **본문 이미지 요청문 복사 → claude.ai 열기** → 붙여넣어 보내기
2. 답변 아래 **복사** → 앱의 칸에 붙여넣고 **적용**
   - 이미지가 만들어지고, 본문의 해당 소제목 아래에 `[이미지 1: 설명]` 자리가 표시됩니다(미리보기에서 그림으로 확인).
   - 코드가 오른쪽 별도 창(아티팩트)에 나오면 claude.ai에 "답변 안에 코드로 다시 써 줘"라고 요청하세요.
3. 네이버에 본문을 붙여넣으면 노란 **[이미지 N 자리]** 안내 줄이 보입니다. 앱에서 **이미지 복사** → 그 자리에 붙여넣기 → 안내 줄 지우기. (**PNG 저장** 후 사진으로 올려도 됩니다)
- 이미지에는 **본문에 있는 내용·숫자만** 쓰도록 지시했고, '확인할 내용'에 관련된 수치는 넣지 않게 했습니다. 그래도 이미지 속 숫자·날짜는 꼭 눈으로 확인하세요.
- 이미지는 가로 1200 기준을 2배(2400px)로 저장해 인쇄해도 또렷합니다.

**대표 이미지 (ChatGPT · 제목 글자 포함)**
1. 대표 이미지에는 **글 제목이 그대로** 들어갑니다(제목이 짧을수록 글자가 정확하게 나옵니다).
2. **대표 이미지 요청문 복사 → ChatGPT 열기** → 붙여넣어 보내기 → ChatGPT가 **제목 글자까지 넣어** 그린 그림을 내려받기
3. 그림을 앱의 상자에 **끌어다 놓기**(또는 그림 복사 후 상자를 누르고 Ctrl+V, 또는 **그림 파일 선택**)
4. 노란 칸의 **"그림에 들어가야 할 글자"**와 그림 속 글자를 비교 → 똑같으면 **확인 체크**
5. **그림 저장** → 네이버에서 사진으로 올리고 대표 사진으로 지정 (또는 **이미지 복사** 후 붙여넣기)
- ⚠ ChatGPT 그림 속 한글은 틀리거나 깨질 수 있습니다. 확인 체크를 하지 않으면 본문 복사 때 한 번 더 알려 드립니다. 글 제목을 고치면 확인 체크는 자동으로 풀립니다.
- 그림은 원본 그대로 `data/images` 폴더에 보관되며 자동 백업에 포함됩니다. (글 목록의 '백업 파일 내려받기' 파일에는 그림이 들어가지 않습니다)

### 이미지 학습 (위쪽 메뉴 '이미지 학습')
본문 이미지(claude.ai)와 대표 이미지(ChatGPT)를 **따로** 학습합니다.
1. 내 블로그에서 쓰던 이미지 3~8장을 상자에 **끌어다 놓기**(또는 파일 선택, Ctrl+V). 앱이 **내 주요 색**을 자동으로 뽑습니다.
2. **① 샘플 모음 이미지 복사** → claude.ai(본문용) 또는 ChatGPT(대표용) 새 대화창에 **Ctrl+V**(그림 첨부)
3. **② 스타일 분석 요청문 복사** → 같은 대화창에 **Ctrl+V** 후 보내기
4. 답변(스타일 지침)을 복사해 칸에 붙여넣고 **스타일 지침 저장**
- 이후 글쓰기 화면 '4. 이미지 만들기'의 **내 본문 이미지 스타일 반영 / 내 대표 이미지 스타일 반영**이 켜져 있으면, 요청문에 내 색과 스타일 지침이 자동으로 들어갑니다(끄면 기본 초록 스타일).
- ⚠ 개인정보가 보이는 이미지는 넣지 마세요(분석할 때 AI 서비스로 보내짐). 샘플은 `data/styleimg` 폴더에 저장되고 자동 백업에 포함됩니다.
- AI를 다시 훈련시키는 것이 아니라, 매번 요청문에 내 색과 지침을 함께 보내는 방식입니다. 완전히 똑같이 나오지는 않을 수 있습니다.

- 원천세·지급명세서·자동차세·재산세·주민세 등 블로그 공지용이 아닌 일정은 넣지 않았습니다. 필요하면 **내 일정 추가**로 넣을 수 있습니다.
- 색깔: 빨강 국세 · 보라 신청·안내 · 초록(✎) 글 추천일 · 파랑 내 글·일정
- **기한 연장**: 기한이 토·일·공휴일·노동절이면 다음 날로 연장해 표시하고, "법정 ○/○ → 연장"으로 원래 날짜도 함께 적습니다.
- **글 추천일**: 일정마다 **안내 글** 1번 — 기한 약 2주 전(기간형은 시작 약 10일 전). 추천일이 주말·공휴일이면 앞 평일로 당깁니다.
- 일정마다 **이 주제로 쓰기**(주제·메모·'신고기한 안내' 템플릿 자동 입력), **발행 예정 등록**(글 목록에 예정 글 생성) 버튼이 있습니다.
- **내 일정 추가**: 거래처 자료 마감 등 개인 일정을 넣을 수 있습니다.
- **휴일 추가**: 정부가 임시공휴일을 지정하면 직접 넣어 주세요. 기한 연장 계산에 반영됩니다.
- 추천 주제 TOP 5 요청문에도 달력 기준 45일 안의 주요 기한이 함께 들어갑니다.
- ⚠ 공휴일 자료는 **2026~2027년**만 들어 있습니다. 다른 해는 토·일요일만 반영되며 화면에 경고가 나옵니다.
- ⚠ 일정 규칙은 법 개정으로 바뀔 수 있습니다. 매년 초 국세청 세무일정·위택스와 비교해 주세요. '확인 필요' 표시가 있는 일정은 특히 확인이 필요합니다.
- 일정 규칙은 `public/taxcal.js` 파일에 모여 있습니다.

### 추천 주제 TOP 5
- **🔄 갱신 버튼 (무료, 바로 갱신)**: 누르면 앱이 아래 자료로 바로 계산합니다. AI를 쓰지 않아 비용이 없습니다.
  1. 세무달력의 다가오는 기한 (가까울수록 높은 순위)
  2. 그 시기에 많이 찾는 세금 주제 (예: 11월 연말정산 미리보기)
  3. 지역 뉴스 제목 (토지보상·개발·지원금·산업단지 등 세금과 연결되는 소식) — 무료 뉴스 검색 사용
  4. 최근 30일 안에 쓴 주제는 순위를 내려 중복을 피함
  - 인터넷이 안 되거나 뉴스를 못 불러오면 달력·시기별 주제로만 추천하고 화면에 안내합니다.
  - 처음 실행할 때 목록이 없으면 자동으로 한 번 갱신합니다.
- **AI 정밀 조사 (선택)**: 아래쪽 **AI 정밀 조사 요청문** → claude.ai(웹 검색 켜기)에 붙여넣기 → 답변 코드 블록 복사 → **답변 붙여넣기** → **적용**. 지역 소식을 더 깊게 조사할 때 씁니다.
- 각 주제 옆 작은 표시(세무달력 / 지역 뉴스 / 시기별 주제 / 지역 주제 / AI 조사)로 추천 근거를 알 수 있습니다.
- **이 주제로 쓰기**를 누르면 주제와 메모가 채워집니다.
- 📍 지역 이름을 누르면 지역을 바꿀 수 있습니다.
- 순위 옆 ▲▼는 직전 조사 대비 순위 변화, NEW는 새로 들어온 주제입니다.
- 막대는 **AI가 추정한 관심도**이며 실제 검색량이 아닙니다.
- (선택) 네이버 데이터랩 키를 `.env`에 넣으면 막대 대신 **실제 최근 4주 검색 추이 그래프**가 표시됩니다.
  - 네이버 개발자센터(developers.naver.com)에서 애플리케이션을 등록하고 '데이터랩(검색어트렌드)' API를 선택해 발급합니다.
  - `.env`에 `NAVER_CLIENT_ID=`, `NAVER_CLIENT_SECRET=` 두 줄로 넣습니다.
  - 데이터랩 수치는 **전국 기준 상대값**(5개 주제끼리 비교한 값)입니다. 안성 지역만의 검색량은 아닙니다.
- 데이터랩은 네이버의 무료 서비스입니다(하루 호출 한도 있음).

### 글 올리는 순서
1. **글쓰기** 화면에서 주제를 넣고 **요청문 복사 → claude.ai 열기**
2. claude.ai 대화창에 붙여넣기(Ctrl+V) 후 보내기
   - "공식 자료 검색"을 체크했다면 claude.ai에서 **웹 검색이 켜져 있는지** 확인하세요.
3. 답변 아래 **복사** 버튼 → 앱의 **claude.ai 답변 붙여넣기** 칸에 붙여넣고 **적용**
   - 제목 후보·본문·해시태그가 자동으로 채워집니다. 마음에 드는 제목 후보를 클릭하면 제목이 바뀝니다.
   - ⚠ 답변을 마우스로 드래그해서 복사하면 소제목(##) 서식이 빠질 수 있습니다. **복사 버튼**을 써 주세요.
4. 본문을 읽고 고칩니다. 본문 아래 **'발행 전 확인할 내용'**을 하나씩 직접 확인해 본문을 고친 뒤 체크합니다. 이 목록은 네이버에 복사되지 않습니다. (예전 글에 [확인 필요] 표시가 남아 있으면 복사할 때 자동으로 빠지며, 복사 전에 알려 드립니다)
5. **2차 검증**: **검증 요청문 복사 → ChatGPT 열기** → ChatGPT에 붙여넣어 보내기 → 답변 아래 **복사** → 앱의 검증 칸에 붙여넣고 **검증 결과 저장**
   - 판정과 항목별 결과(수정안·근거)가 표시됩니다. **수정 필요** 항목은 근거를 직접 확인한 뒤 본문에 반영하세요.
   - 검증 후 본문을 고치면 "검증 이후 본문이 수정되었습니다" 안내가 나옵니다. 크게 고쳤다면 다시 검증하세요.
   - 검증을 안 했거나 판정이 '수정 후 발행·발행 보류'이면 본문 복사 때 한 번 더 확인 창이 뜹니다.
   - ChatGPT 계정이 필요합니다. 웹 검색이 되는 상태에서 보내면 최신 법령 확인이 더 정확합니다.
   - **수정본 만들기**: 검증 결과 아래 **수정본 요청문 복사 → claude.ai 열기** → 붙여넣어 보내기 → 답변 복사 → **수정본 적용**
     - '수정 필요' 항목과 '확인할 내용' 확인 결과만 고치고 나머지 문장·말투는 그대로 둡니다.
     - claude.ai가 검증 의견을 다시 확인해, 틀렸다고 판단한 의견은 **미반영**과 이유를 적습니다.
     - 적용 후 **수정 내역**(반영/미반영)이 표시됩니다. 마음에 안 들면 **수정 전으로 되돌리기**를 누르세요.
     - 수정본은 다시 한 번 2차 검증하는 것을 권합니다.
6. **저장** (Ctrl+S)
7. **네이버 글쓰기 창 열기** → 제목 복사·붙여넣기 → 본문 복사·붙여넣기 → 태그는 **'다음 태그 복사'를 눌러 하나씩** 붙여넣기(Ctrl+V → Enter, 네이버 태그 칸은 한꺼번에 붙여넣으면 하나로 뭉침)
8. 네이버에서 발행한 뒤, 글 주소를 **네이버 글 주소** 칸에 넣고 상태를 **발행 완료**로 저장

## 꼭 지켜 주세요

- **2차 검증은 보조 수단입니다.** 두 AI가 같은 내용을 똑같이 틀릴 수도 있으니, 최종 확인은 세무사님이 법령·국세청 자료로 해 주세요.
- **AI 초안을 그대로 발행하지 마세요.** 세율·공제한도·기한은 반드시 직접 확인해야 합니다. '발행 전 확인할 내용'을 다 체크하지 않았으면 복사할 때 알려 드립니다.
- 고객 실명·주민등록번호·계좌번호 등 **개인정보를 메모나 내 글 학습에 넣지 마세요.** 요청문에 그대로 들어가 claude.ai로 보내집니다.
- 세무사 광고 관련 규정에 어긋나는 표현(과장·비교·단정 표현 등)이 없는지 발행 전에 확인해 주세요. AI에는 이런 표현을 피하도록 지시해 두었습니다.
